# The Movie Spoiler → SQLite

Скрипт собирает ссылки на фильмы с https://themoviespoiler.com/ и сохраняет полные тексты страниц фильмов в локальную SQLite-базу `spoilers.db`. Сначала использует WordPress sitemap, при отсутствии ссылок переходит к HTML-архиву. Повторный запуск пропускает сохранённые записи.

## Windows

Установи Python 3, затем запусти `run.bat` (двойным щелчком). Или из командной строки:

```bat
cd movie_spoiler
py -3 -m pip install -r requirements.txt
py -3 movie_spoiler_scraper.py --limit 5
py -3 movie_spoiler_scraper.py
```

Для первого теста используй `run.bat --limit 5` из командной строки либо команду выше. Без параметров `run.bat` запускает полный сбор.

## Параметры

- `--limit 5` — обработать не более 5 новых фильмов
- `--refresh` — заново загрузить уже сохранённые записи
- `--db other.db` — выбрать путь к базе
- `--delay 3` — пауза между запросами (не меньше 1 сек.)
- `--pages 100` — глубина обхода HTML-архива в резервном режиме
- `--verbose` — подробные логи

## SQLite

Таблица `movies`: `url` (первичный ключ), `title`, `year`, `plot`, `published_at`, `genres`, `fetched_at`.

Пример поиска:

```sql
SELECT title, year, substr(plot, 1, 250) FROM movies WHERE title LIKE '%monkeys%';
```

Данные `spoilers.db` создаются локально, в Git не добавляются. Скрипт останавливается при HTTP 403/429; не пытайся обходить ограничения сайта. Перед массовой загрузкой и повторным использованием текстов проверь правила сайта и права правообладателей. Фактический сбор с живого сайта не подтверждён, если HTML-разметка отдельного фильма отличается, потребуется настроить селекторы.
