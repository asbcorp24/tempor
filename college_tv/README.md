# Электронное расписание колледжа

Веб-приложение на Flask и SQLite для показа расписания из XML «Ректор-Колледж» на телевизоре.

## Возможности

- Показывает **понедельник–субботу** текущей недели одновременно.
- **8 групп на странице**, переключение каждые **5 секунд**.
- Сохраняет и выводит **подгруппы** (`п/г 1`, `п/г 2`) и кабинеты.
- Не показывает преподавателей на телевизоре.
- Рассчитано на телевизор **1980 × 1020** (страница адаптируется к другим размерам).
- Проверяет обновления расписания каждые 30 секунд.
- Администратор может загрузить новый XML в браузере.

## Запуск на Windows

Установите Python 3.10+ и дважды нажмите **`start_college_tv.bat`**. Батник создаст `.venv`, установит зависимости и запустит приложение.

## Запуск на Linux / macOS

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app.py
```

- http://localhost:5000/tv — экран телевизора. Для полноэкранного режима нажмите `F11`.
- http://localhost:5000/admin — загрузка XML.
- Для телевизора в той же локальной сети используйте `http://IP-КОМПЬЮТЕРА:5000/tv`.

База `schedule.db` включена в проект и уже содержит расписание из файла «Осень 2026». Новые XML загружаются через `/admin`.

## Важно

В текущей версии `/admin` **не защищён паролем**. Используйте приложение только в доверенной локальной сети, не открывайте порт 5000 в интернет. Для публичного доступа требуются авторизация, HTTPS и production WSGI сервер.

## Структура

- `app.py` — Flask, импорт XML, API по неделям.
- `templates/tv.html` — телевизионный экран.
- `templates/admin.html` — загрузка расписания.
- `schedule.db` — SQLite с исходным импортом.
- `start_college_tv.bat` — запуск на Windows.

## API

`GET /api/week?date=2026-11-16` возвращает расписание на неделю, содержащую указанную дату, включая подгруппы. Если дата не передана, используется текущая дата сервера.
