# Электронное расписание колледжа

Веб-приложение на Flask и SQLite для показа расписания из XML «Ректор-Колледж» на телевизоре.

## Возможности

- Показывает **понедельник–субботу** текущей недели одновременно.
- **8 групп на странице**, переключение каждые **5 секунд**.
- Сохраняет и выводит **подгруппы** (`п/г 1`, `п/г 2`) и кабинеты.
- Не показывает преподавателей на телевизоре.
- Рассчитано на телевизор **1980 × 1020** (страница адаптируется к другим размерам).
- Проверяет обновления расписания каждые 30 секунд.
- Администратор может загрузить новый XML в браузере.

## Запуск на Windows

Установите Python 3.10+ и дважды нажмите **`start_college_tv.bat`**. Батник создаст `.venv`, установит зависимости и запустит приложение.

## Загрузка первоначального расписания

Бинарная SQLite-база **не включена в GitHub-репозиторий**. При первом запуске автоматически создастся пустая база `schedule.db`. Затем откройте http://localhost:5000/admin и загрузите исходный XML «Осень 2026 (1).xml». Либо скопируйте готовый файл `schedule.db` из ранее скачанного архива рядом с `app.py` перед запуском.

После загрузки XML страницы телевизора обновятся автоматически, ручная перезагрузка не требуется.

## Запуск на Linux / macOS

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app.py
```

- http://localhost:5000/tv — экран телевизора. Для полноэкранного режима нажмите `F11`.
- http://localhost:5000/admin — загрузка XML.
- Для телевизора в той же локальной сети используйте `http://IP-КОМПЬЮТЕРА:5000/tv`.

## Важно

В текущей версии `/admin` **не защищён паролем**. Используйте приложение только в доверенной локальной сети, не открывайте порт 5000 в интернет. Для публичного доступа требуются авторизация, HTTPS и production WSGI сервер.

## Структура

- `app.py` — Flask, импорт XML, API по неделям.
- `templates/tv.html` — телевизионный экран.
- `templates/admin.html` — загрузка расписания.
- `schedule.db` — локально создаваемая база SQLite (не отслеживается в Git).
- `start_college_tv.bat` — запуск на Windows.

## API

`GET /api/week?date=2026-11-16` возвращает расписание на неделю, содержащую указанную дату, включая подгруппы. Если дата не передана, используется текущая дата сервера.

## Сборка EXE для Windows

Запустите `build_exe.bat` в папке `college_tv`. Требуются Python 3 и интернет для первой установки PyInstaller. После успешной сборки появится `dist/CollegeTV.exe`. Для запуска EXE Python не нужен. При первом запуске EXE создаст `schedule.db` в той же папке, где лежит EXE; XML загрузите через `http://localhost:5000/admin`. Не переносите EXE в защищённую от записи папку вроде `Program Files`. Сборку выполняйте на Windows. Готовый EXE в репозиторий не включён.

## Просмотр других недель

На странице `/tv` вверху расположены небольшие кнопки `◀`, `Текущая`, `▶`. Они переключают неделю назад, на текущую или вперёд. Можно открыть конкретную неделю напрямую: `http://localhost:5000/tv?date=2026-11-02`. Дата сохраняется в адресной строке; автоматическое перелистывание страниц групп каждые 5 секунд продолжает работать.

## Автоматическое открытие телевизионной страницы

При запуске `start_college_tv.bat` или `CollegeTV.exe` сервер ожидает готовности и автоматически открывает `http://localhost:5000/tv` в браузере по умолчанию. Для отключения можно задать переменную окружения `COLLEGE_TV_NO_BROWSER=1` до запуска. Полноэкранный режим браузера включается клавишей `F11`.

## Отображение подгрупп

Внутри каждого дня занятия объединяются по номеру пары. Если у пары одновременно идут занятия у двух подгрупп, строка делится пополам; у трёх — на три равные части. В каждой части показаны подгруппа, предмет и кабинет. Длинные названия обрезаются многоточием, полное содержимое доступно при наведении мыши. Если в паре присутствует общая запись без номера подгруппы и отдельные подгруппы, общая запись показывается в отдельной колонке.
